# Project videos

Drop any video file here and it will automatically appear on the /projects
page under the "Videos" tab — no code changes needed.

Supported formats: .mp4, .webm, .mov, .m4v, .ogg

Tips:
- Name the file the way you want it captioned (spaces/dashes become the title).
- Keep videos reasonably compressed (web-friendly .mp4/H.264) for fast loading.
- In dev mode (`npm run dev`) new files show up on refresh. In production
  you need to rebuild/redeploy the site after adding files.
