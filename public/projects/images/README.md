# Project photos

Drop any photo file here and it will automatically appear on the /projects
page — no code changes, no importing, no registering it anywhere.

Supported formats: .png, .jpg, .jpeg, .webp, .gif, .avif

Tips:
- Name the file the way you want it captioned, e.g. `Modern Living Room.jpg`
  or `modern-living-room.jpg` — both become "Modern Living Room" on the site.
- Files are sorted by filename, so prefix with numbers (01-, 02-, ...) if you
  want to control the order.
- In dev mode (`npm run dev`) new files show up on refresh. In production
  you need to rebuild/redeploy the site after adding files.
